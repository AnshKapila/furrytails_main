Apply a consistent default timing for hover animations on this website.

## Rule
Set hover animation duration to 800ms by default for hover-driven interactions unless the user explicitly requests a different duration.

## Applies to
Use this for image hover effects, text reveal hovers, card hover states, button hover states, color transitions, saturation changes, and similar hover-based interface behavior.

## Do not change
Do not change non-hover animations just to match this rule unless the task specifically asks for interaction-system consistency.

## Priority
If the user gives a different timing for a specific interaction, follow the user's explicit request for that case.
